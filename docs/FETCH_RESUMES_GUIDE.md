# Руководство по функции Fetch Resumes

## Обзор

Функция `fetch_resumes` автоматически загружает резюме из email и подготавливает их для быстрого поиска.

## Как это работает

### 1. Подключение к email
- Использует IMAP для подключения к почтовому серверу (Gmail по умолчанию)
- Ищет непрочитанные письма с вложениями
- Поддерживаемые форматы: `.pdf`, `.doc`, `.docx`, `.txt`, `.png`, `.jpg`, `.jpeg`

### 2. Сохранение резюме
- Скачивает вложения в `backend/data/resumes/`
- Автоматически декодирует имена файлов (поддержка кириллицы)
- Пропускает дубликаты (если файл уже существует)

### 3. Автоматическая генерация эмбеддингов
**Новая фича!** После загрузки резюме автоматически:
- Парсит новые резюме через LLM
- Генерирует эмбеддинги в batch mode (быстро!)
- Кэширует в `backend/data/embeddings_cache/`

**Результат**: Поиск кандидатов будет мгновенным даже для только что загруженных резюме!

## Использование

### Через API

```bash
# Загрузить резюме с автоматической генерацией эмбеддингов
curl -X POST "http://localhost:8000/fetch-resumes?max_emails=5&precompute_embeddings=true"

# Загрузить резюме без генерации эмбеддингов (не рекомендуется)
curl -X POST "http://localhost:8000/fetch-resumes?max_emails=5&precompute_embeddings=false"
```

### Через Streamlit UI

1. Откройте боковую панель
2. Нажмите кнопку "🔄 Fetch New Resumes"
3. Подождите завершения (появится сообщение об успехе)

### Программно

```python
from backend.app.email_client import EmailClient

email_client = EmailClient()

# Загрузить последние 5 непрочитанных писем
saved_files = email_client.fetch_resumes(
    unread_only=True,
    max_emails=5
)

print(f"Загружено {len(saved_files)} резюме")
```

## Параметры

### `/fetch-resumes` endpoint

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `max_emails` | int | 5 | Максимум писем для обработки |
| `precompute_embeddings` | bool | true | Генерировать эмбеддинги автоматически |

### `EmailClient.fetch_resumes()`

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `folder` | str | "INBOX" | Папка для поиска |
| `unread_only` | bool | True | Только непрочитанные письма |
| `max_emails` | int | 50 | Максимум писем для обработки |

## Настройка

### Конфигурация email в `.env`:

```env
# Email Configuration
EMAIL_ADDRESS=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
IMAP_SERVER=imap.gmail.com
IMAP_PORT=993
```

### Для Gmail:

1. **Включить 2FA**: Настройки → Безопасность → Двухфакторная аутентификация

2. **Создать пароль приложения**:
   - Перейти в: https://myaccount.google.com/apppasswords
   - Создать новый пароль для "Почта"
   - Скопировать 16-значный пароль
   - Вставить в `.env` как `EMAIL_PASSWORD`

3. **Включить IMAP**:
   - Gmail → Настройки → Пересылка и POP/IMAP
   - Включить IMAP

## Возможные проблемы

### 1. Authentication failed

**Проблема**: Неверный пароль или email

**Решение**:
- Проверьте `.env` файл
- Убедитесь, что используете пароль приложения (не основной пароль)
- Для Gmail: создайте App Password

### 2. No messages found

**Проблема**: Нет непрочитанных писем с резюме

**Решение**:
- Отправьте тестовое письмо с вложением резюме
- Используйте `unread_only=False` для поиска среди всех писем
- Проверьте папку INBOX

### 3. Timeout errors

**Проблема**: Слишком много писем для обработки

**Решение**:
- Уменьшите `max_emails` (например, до 5)
- Обрабатывайте письма порциями

### 4. Embeddings not generated

**Проблема**: Поиск медленный для новых резюме

**Решение**:
- Убедитесь, что `precompute_embeddings=true` (по умолчанию)
- Или запустите вручную: `python -m backend.precompute_embeddings`

## Производительность

### Время обработки:

| Операция | Время |
|----------|-------|
| Подключение к email | ~1-2 сек |
| Скачивание 1 резюме | ~0.5-1 сек |
| Парсинг резюме (LLM) | ~2-3 сек на резюме |
| Генерация эмбеддингов (batch) | ~3-5 сек для 5 резюме |

**Итого для 5 новых резюме**: ~15-20 секунд

### Оптимизация:

- **Batch processing**: Все эмбеддинги генерируются за 2 вызова вместо 10
- **Кэширование**: Повторные резюме обрабатываются мгновенно
- **LLM caching**: Парсинг кэшируется в `data/resumes_parsed/`

## Рекомендации

1. **Включайте автоматическую генерацию эмбеддингов**
   - По умолчанию `precompute_embeddings=true`
   - Гарантирует быстрый поиск сразу после загрузки

2. **Ограничивайте количество писем**
   - Используйте `max_emails=5` для быстрой обработки
   - Запускайте периодически, а не обрабатывайте все сразу

3. **Мониторьте логи**
   - Проверяйте успешность парсинга
   - Следите за ошибками генерации эмбеддингов

4. **Периодически очищайте старые резюме**
   - Удаляйте неактуальные файлы из `backend/data/resumes/`
   - Очищайте соответствующий кэш из `backend/data/embeddings_cache/`

## Интеграция с системой поиска

После выполнения `fetch_resumes`:

1. **Резюме сохранены**: `backend/data/resumes/`
2. **Эмбеддинги созданы**: `backend/data/embeddings_cache/`
3. **Готовы к поиску**: Можно сразу использовать `/recommendations`

**Поиск будет мгновенным** благодаря предварительно созданным эмбеддингам!
